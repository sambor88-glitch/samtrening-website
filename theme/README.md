# theme/

Miejsce na kod, który działa na produkcji.

Docelowo: `theme/samtrening-2026/` — motyw WordPressa ze strony samtrening.com.
Dziś katalog jest pusty, bo motyw żyje wyłącznie na serwerze (Lightsail) i nikt go jeszcze
nie wyciągnął do gita.

Jak go tu wstawić, krok po kroku — z komendami i listą rzeczy do sprawdzenia przed commitem
(sekrety!) — opisuje [`../docs/wdrozenie-motywu.md`](../docs/wdrozenie-motywu.md).

Do repozytorium trafia sam kod motywu. Baza danych i `wp-content/uploads` zostają poza gitem:
treści i zdjęcia są zarządzane w panelu WordPressa.
